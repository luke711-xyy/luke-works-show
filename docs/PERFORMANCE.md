# 移动端性能优化 · 2026-10-20

本轮保留既有宣纸、水墨荷叶、锦鲤、中文器物模型与真实 Bayer 抖色，不用静态图标替换动态场景。

## 一级与二级切换提速 · 2026-10-21（本地）

保留同一连续世界坐标、屏幕外荷叶缓冲区及 smoothstep 起止缓动，只调整飞行时长。设本次实际移动距离为 d 个视口宽，以旧版时长除以 `1.5 × (1 + 0.35 × log2(max(1, d)))`：一屏、两屏、四屏、八屏分别为约 1.50、2.025、2.55、3.075 倍速度。补偿随距离增加、每多一屏的增幅递减；进入与返回共用绝对距离规则。减少动态与直接链接仍立即定位。

实际应用夹具在本机 Chromium 采样远端 LanBridge 的冷进入／返回／暖进入：1280×700 约 572／588／580ms，390×700 约 503／535／540ms。这是浏览器墙钟样本，包含绘制调度，不是恒定耗时承诺或真机手机性能保证。原始记录位于 `.impeccable/review/journey-speed-after.json`。本节调整尚未推送或部署。

## 定位与处理

- 手机地址栏伸缩导致 `resize` 时，旧实现会释放并重建整池几何、材质和模型。现在同宽的竖屏高度变化只重排对象并调整相机，保留资源与动画对象。
- 首屏不再同步构造八个复杂项目徽记；首帧后在空闲任务逐个预热，优先选择项目和视角附近模型，创建时立即绑定深度带和接缝裁切。入卷及返回飞行期间不构造模型，预编译使用与实际 Bayer 绘制一致的离屏目标，完成后才显示。
- 640px 以下使用 1× 绘制缓冲、30fps 动画预算；叶面从 7,488 减至 3,456 个三角形，保持相同轮廓、褶皱函数、宽幅积墨和受光配色。桌面保留完整几何与 1.5× 上限。
- WebGL 模块从入口拆出，语义 DOM 先显示。入口业务 JS 从约 102.3kB 降至 42.9kB；Three.js 与模型代码仍需要按模块下载，并非消失。
- 案例导航状态提交后立即暂停场景绘制，不再与对话框展开、截图解码竞争；历史状态写入失败不阻塞界面。`pointerup` 仅确认轻点，最终 `click` 统一展开项目，避免提前替换命中界面导致兼容点击穿透到新图片；不加全局延迟或吞掉后续主动点图。距离阈值、原生横滑取消、鼠标及键盘保持可用。
- 修复首帧 RAF 时间戳稍早于场景初始化时的负动画时间，防止编钟索引越界。
- 手机默认使用从原图生成的 720px 原彩 WebP（quality 92），23 张合计约 1.2MB；三级图片不再做 Bayer 量化。桌面清晰大图、原图查看和视频按需播放保留；一、二级程序场景继续真实抖色。
- 入卷、长卷当前项、指针意图及按下时预热封面；低优先级预热串行执行，离开即取消后续队列。详情只主动预热下一张，后续由原生 lazy loading 跟随滚动；省流量/2G 不做后台预热。内存最多保留 12 张预热图。
- `public/_headers` 对哈希 JS/CSS 与哈希手机版图片使用一年 immutable，对可变图片/字体/宣纸使用短缓存与重验证。不缓存整站 HTML，不引入可能固化旧应用的全站离线 Service Worker。

## 验证边界

2026-10-21 手机鱼名显隐：只在首页且为紧凑／触摸布局时计算鱼身露出。复用 21 个采样点、遮挡位掩码和坐标缓存，不读回 GPU；叶片沿用已有投影轮廓。390px 构图中四个花头从既有几何一次提取并保留 128 个轮廓点，之后仅投影这些缓存点，不逐帧扫描花瓣网格或重建凸包。名称只在显隐状态变化时写入属性。桌面 hover-only 布局及二级界面跳过这部分采样；新原生 SVG 光标也不新增 RAF。此处描述工作量边界，不承诺未经真机测量的帧率提升。

2026-10-21 连续入卷优化：`tests/journey-performance.html` 使用实际应用 iframe、真实 WebGL 渲染与 DOM 同步，分别采样 1280×700 和 390×700。首页右侧根据完整轮廓和扰动余量保留持续存在的屏幕外空间，原首屏构图不变；纸纹与入口位移改走合成层，隐藏锦鲤跳过顶点形变。修改前后同机样本中，冷入卷帧 CPU 耗时 P95：电脑约 7.2→5.6ms，手机尺寸约 10.4→5.8ms；渲染回调间隔 P95：电脑约 21.8→22.2ms（未改善），手机尺寸约 39.5→34.6ms。样本来自本机桌面 Chromium，包含浏览器调度波动，不是 GPU 计时、真机手机帧率或公网慢网保证；空闲创建可发生在最后一个采样回调之后，不等于仍在相机飞行帧中构造。原始报告在 `.impeccable/review/journey-performance-before.json` 和 `journey-performance-after.json`，不公开发布。

新增回归覆盖完整右侧叶片、持续缓冲边界、往返／中途 resize、飞行中不构造模型、空闲预热取消、预编译目标与完成后显示，以及健康场景收到 WebGL 丢失事件后的可用回退网格。

上述优化阶段，本地桌面 Chromium 的 390×700/720 iframe，同一检查夹具测得：高度变动停顿约 299 → 20ms；原生鼠标点击至 dialog 打开约 49 → 27ms；当时的独立触摸事件路径约 21ms。它们是历史本机样本，不是后续输入修复的计时结果，也不是真机或公网慢网性能保证；iframe RAF 间隔也不是 GPU 渲染帧率。

回归覆盖：手机高度变化不释放几何、首页不构造离屏徽记、按需徽记的深度带、绘制缓冲预算、案例打开立即暂停/关闭恢复、首帧负时钟、低优先级请求升级、预热串行与取消、移动图片路由及内容哈希。另校验 24 个原始素材哈希、23 张清晰图像素一致性、48 个既有媒体 URL。

重新生成手机版资源：`npm run assets:responsive`；完整素材准备 `npm run assets` 也会同步生成。新文件在 `public/media-mobile/`，内容哈希用于更新失效，版本信息在 `src/data/media-responsive.generated.json`。

缓存头已随 2026-10-21 的鱼鳍细化版本发布；后续导航及题字更新也已随 `9623619a` 发布，证据见 `docs/DEPLOYMENT.md`。实际手机、移动网络及重复访问条件下的性能仍需实机复测，不以桌面尺寸模拟代替。
