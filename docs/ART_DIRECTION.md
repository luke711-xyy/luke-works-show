# 荷塘与作品长卷的视觉约定

## Direction contract

THESIS：作品是水下的锦鲤，拨叶是发现动作；选中的鱼把访客带进作品长卷。

OWN-WORLD：暖黄宣纸、深浅墨灰荷叶、灰粉紫荷花、朱红至金黄及象牙白锦鲤；真实有序抖色覆盖场景与媒体。宋体标题与清晰中文正文保持克制。

STORY：先以少量动作探索，再沿鱼游览，最后进入项目的真实证据与实现。

FIRST VIEWPORT：斜俯视、密集且不均匀的交叠叶片，水面缝隙不规则。八条鱼在各自区域持续随机游动，多数时候受遮挡。项目名跟随已显露或聚焦的鱼，一句轻提示位于安静角落。

FORM：用户指定的荷塘世界；reference: user-pinned。已确认 code-first；概念图为构图参考，实际运动和材质以浏览器样片验收。

权威依据为用户原话：“整体风格滤镜严格采用 dithering”“用低饱和的粉紫和中式水墨（不同颜色深度的黑灰）来分别表现荷花与荷叶的颜色”“主页面是一片斜上方看过去的荷塘”。这是 human-pinned FORM bypass，不存在随机方向种子，不能虚构 seed。两张概念图仅为非绑定参考。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

## 材质与比例

- 纸色以 #ead3a0 为基底，较暖黄，保留细密低对比颗粒与少量纤维。
- 叶片保留深浅水墨层级，卷边、受光褶皱及宽幅色块混入 #dcd9cd 浅灰蜡白，暗部仍保留积墨；不用等宽白描边、绿色荧光或玻璃质感。
- 盛开荷花根部及中段偏暖白 #f2eee8，边缘与瓣尖过渡至 #a87898、#b583a0 粉紫色；加入一至两枚有花茎与花萼的闭合花苞。
- 鱼使用朱红 #b94432、橙 #d88039、金黄 #d8ad55、象牙白 #f1e6c8，眼与少量纹理为墨色。
- 标题与 UI 像素质感适量，主体画面与空白承担表达；首页无巨型标题、简介或技术标签。
- 长卷项目叶尺寸与姿态错落，图形独立制作；不使用一排同样大小的标准卡片。
- 每片荷叶是完整的独立遮挡层，重叠时只有明确的前后覆盖，不因褶皱相互切穿；所有盛开荷花与花苞在全部荷叶之上。层级修正保留内部三维深度、光影和 Bayer 抖色。
- 一级界面右端只连接二级界面最左端。相机先经过接缝，再快速滑到所选作品；返回沿原路滑回，不把远端内容提前移到接缝，也不让两侧植物跨边界叠画。

## 检查顺序

先看缩略图是否仍能认出荷叶、荷花与锦鲤，再看局部颗粒。先看静态层次，再连续观察扰动、游动、切屏和绕行。所有反馈先集中成一批，再修改与复核。
